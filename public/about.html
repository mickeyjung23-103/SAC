"죄수의 딜레마"란?

두 명의 플레이어가 '협력' 또는 '배신' 중 하나를 선택하는 게임입니다.
두 플레이어의 선택에 따라 각자가 얻는 점수가 달라집니다.

이 게임의 '딜레마'는, 두 플레이어 모두에게 최선인 선택이 있지만, 개인의 이익을 쫓다 보면 결국 둘 다 최악의 결과에 도달하게 된다는 점입니다.

게임 규칙

모든 참가자는 DB에 저장된 다른 모든 전략과 한 번씩 대결(매치)을 펼칩니다.
각 매치는 80~120턴 사이의 무작위 길이로 진행되며, 턴마다 점수가 누적됩니다.

점수표 (나, 상대)
상대가 '협력' 상대가 '배신'
내가 '협력' (나: 3점, 상대: 3점) (나: 0점, 상대: 5점)
내가 '배신' (나: 5점, 상대: 0점) (나: 1점, 상대: 1점)

토너먼트 종료 후, 모든 매치에서 얻은 '총 점수'를 '총 턴수'로 나눈 평균 점수로 순위가 결정됩니다.

코드 제출 방법

Python 함수 strategy를 작성하여 제출해야 합니다. 이 함수는 매 턴마다 호출됩니다. 

def strategy(opponent_history, my_history):
    """
    opponent_history: 상대의 이전 행동 리스트 (e.g., ['협력','배신'])
    my_history: 나의 이전 행동 리스트 (e.g., ['협력','협력'])
    
    반환값: '협력' 또는 '배신'
    """
    
    # 팃포탯 (Tit for Tat) 전략 예시
    if not opponent_history:
        # 첫 턴에는 무조건 협력
        return '협력'
    
    # 직전 턴에 상대가 한 행동을 그대로 따라하기
    if opponent_history[-1] == '협력':
        return '협력'
    else:
        return '배신'
  • opponent_history: 상대방의 행동 기록이 리스트로 주어집니다. 턴이 진행될수록 ['협력', '배신', '협력', ...]처럼 누적됩니다.
  • my_history: 나의 행동 기록이 리스트로 주어집니다.
  • 첫 턴에는 두 리스트 모두 비어있습니다. ([])
  • 반환값은 반드시 문자열 '협력' 또는 '배신'이어야 합니다.

기술적 제한

  • 시간 제한: 각 매치마다 총 0.1초(MATCH_TIME_BUDGET_SEC)의 실행 시간 예산이 주어집니다. 이 시간을 초과하는 계산은 시간초과로 탈락 처리됩니다.
  • 무한 루프: while True:, time.sleep(10) 등 고의적인 지연 코드는 내부 검증 단계에서 적발되어 즉시 탈락 처리됩니다.
  • 모듈 제한: math, random, statistics, itertools와 같은 모듈을 import 하는 것은 불가합니다.
  • 금지 행위: 파일 입출력(open), eval, exec 등 위험한 내장 함수는 모두 차단됩니다.
